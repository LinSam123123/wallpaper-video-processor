# Bundled typography fonts

The renderer bundles only the font weights used by its typography presets:

- Newsreader 500
- Source Sans 3 400, 500, and 600
- Noto Serif SC 500
- Noto Sans SC 400, 500, and 600

The font files are provided by the corresponding `@fontsource` packages and
are licensed under the SIL Open Font License 1.1. See `OFL-1.1.txt` in this
directory and the copyright notices in `THIRD_PARTY_NOTICES.md`.
